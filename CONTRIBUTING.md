# Contributing

Corrections that improve reproducibility, accessibility, or the accuracy of the public evidence are welcome.

## Before opening a change

1. Read `methodology/LIMITATIONS.md` and the public data dictionary.
2. Keep formal observations, survey layers, and validation checks as separate estimands.
3. Do not add participant-level information, account identifiers, logged-in captures, private prompts, or local paths.
4. Explain which public artifact or row supports the proposed correction.

For a code change, run `pnpm check` and include the result in the pull request. For a research correction, identify the affected file, field, and interpretation.
